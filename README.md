# outdated/

Thư mục này lưu các **phiên bản cũ** của file spec trước mỗi lần sửa đổi nội dung, theo quy tắc archive bắt buộc mô tả trong `CLAUDE.md` ở thư mục gốc dự án.

Quy tắc đặt tên: `<tên-file-gốc>__v<version-cũ>__<YYYY-MM-DD>.md`

Ví dụ: `04-security-spec__v0.4.1__2026-09-17.md` — là bản `04-security-spec.md` ở version `v0.4.1`, được archive ngày 2026-09-17 trước khi sửa lên version tiếp theo.

Thư mục này hiện đang trống — chưa có lần cập nhật spec nào được thực hiện kể từ khi thiết lập quy tắc archive (2026-09-17). File đầu tiên sẽ xuất hiện ở đây từ lần sửa spec tiếp theo trở đi.
